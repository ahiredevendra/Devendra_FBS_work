# 📚 Book Management System in C

A console-based Book Management System developed using **C Programming**. This project allows users to manage book records efficiently through a menu-driven interface.

The application demonstrates the practical implementation of C programming concepts such as structures, pointers, arrays, functions, string handling, sorting algorithms, and dynamic memory allocation.

## 🚀 Features

The system provides the following functionalities:

### 1. Add Book
- Add new book records.
- Store Book ID, Name, Author, Category, Price and Rating.
- Prevent duplicate Book IDs and book names.
- Validate negative IDs and prices.

### 2. Remove Book
- Delete a book using its unique Book ID.
- Rearrange records after deletion.

### 3. Search Book by ID
- Search for a specific book using its ID.
- Display complete book information.

### 4. Search Book by Name
- Search books using their names.
- Supports case-insensitive partial name matching.

### 5. Search Books by Author
- Display books written by a particular author.
- Supports case-insensitive searching.

### 6. Search Books by Category
- Find books belonging to a particular category.
- Supports partial category matching.

### 7. Update Book Details
- Update existing book information.
- Modify Price, Rating, Author and Category.

### 8. Display All Books
- Display all available book records in a formatted table.

### 9. Top 3 Books by Price
- Sort books from highest to lowest price.
- Display the three most expensive books.

### 10. Top 3 Books by Rating
- Sort books according to their ratings.
- Display the three highest-rated books.

## ⚙️ How It Works

1. The program initializes with 10 predefined book records.
2. A menu-driven interface allows users to select operations.
3. Users can add, delete, search and update book records.
4. Dynamic memory allocation increases storage capacity when required.
5. Sorting functions identify the top three books by price and rating.
6. The program continues running until the user selects Exit.
